# 화면 크기와 어절 줄바꿈 검증

일반 화면 문구는 `WordSafeText`로 표시한다. 어절이 남은 너비에 들어가지 않으면 다음 줄로 넘기며, 한 어절 자체가 화면보다 길 때는 글자 단위로 나눈다. 기존 줄바꿈과 빈 문단은 유지한다. `maxLines`로 명시한 한 줄·말줄임 표시에는 기존 Text 동작을 유지한다. 스크린리더에는 단어별로 쪼갠 문장이 아니라 원문 전체를 전달한다.

강아지 방은 높이가 부족하면 세로 스크롤이 가능하다. 긴 이름과 레벨을 별도 줄에 표시하며, 돌봄 상태는 사용 가능한 너비와 글자 크기에 맞춰 2열 또는 4열로 표시한다. 운영체제의 글자 크기와 앱 글자 크기 설정을 함께 반영한다.

자동 화면 테스트: `Frontend/mira/test/device_layout_test.dart`

| 화면 크기 (논리 픽셀) | 글자 배율 |
| --- | --- |
| 320 × 640 | 1, 1.4, 2 |
| 360 × 740 | 1, 1.4, 2 |
| 390 × 844 | 1, 1.4, 2 |
| 844 × 390 (가로) | 1, 1.4, 2 |
| 768 × 1024 | 1, 1.4, 2 |
| 1440 × 900 | 1, 1.4, 2 |

로그인, 가족 설정, 반려견 설정, 개인정보 안내, 긴 이름을 가진 강아지 방과 말풍선, 홈·펫·가족·사진첩·MIRA·설정 탭을 검사한다. 별도 기존 테스트에서 채팅 키보드, 성격 질문, 긴 단어, 빈 줄, 카드 배치도 확인한다. 외부 서버의 실제 데이터를 이용하는 물리 기기 테스트를 대체하지는 않는다.

Windows 실행: `Frontend/mira/run.ps1 -Mode verify`.
