# 강아지 방: 기다리기와 성장

- 기다리기는 오늘 배정된 돌봄이 미완료인 가족을 대상으로 한다. 로그인한 본인은 기다릴 대상에서 제외한다. 한국시간 기준 밥 12시, 목욕·놀기 18시, 재우기 21시부터 표시하며, 오전 0~8시에는 표시하지 않는다. 기존 돌봄별 알림 시각 기준을 유지했다.
- 기다리기 버튼은 이전처럼 하나만 표시한다. 한 가족을 기다렸다가 방으로 돌아오면 다음 미완료 가족을 표시하고, 모두 기다렸으면 다시 순환한다. 완료되거나 가족에서 나간 담당자는 제외한다. 선택한 담당자가 빠지면 방으로 돌아온다. 기다리기 자체는 돌봄 완료로 기록하지 않는다.
- `!`는 로그인 UID와 가족 문서의 역할을 연결해 현재 사용자에게 말을 건다. 본인의 미완료 돌봄과 강아지의 부족한 상태를 말풍선에 보여준다. 기다리는 대상이 다른 가족이면 제삼자로 언급한다. 별도 대화 버튼의 채팅에도 현재 대화 상대와 호칭을 전달한다.
- 반려견 설정의 ‘반려견에게 듣고 싶은 호칭’에 사용자가 원하는 호칭을 직접 입력한다. 가족 펫 프로필의 `addresses`에 사용자 UID별로 저장하고 본인 항목만 병합 갱신한다. 말풍선·기다리기·채팅에 직접 지정한 호칭을 우선 적용한다. 미입력한 기존 사용자는 이전 역할·성별 기본 호칭을 유지한다. 강아지 방의 호칭 설정 버튼과 성별에 따른 호칭 설명은 표시하지 않는다.
- `캐릭터.md`의 경험치 구간과 성체 이후 500 XP당 1레벨 계산을 사용한다.
- 초기 보상은 구현 기본값으로 Lv.6 옷장·리본, Lv.16 봄빛 방 꾸미기를 제공한다. 문서에서 정하지 않은 해금 시점이므로 기획에 맞춰 조정할 수 있다.
- Lv.32 모자, Lv.33 모션, Lv.34 배경, Lv.35 쿠폰부터 4레벨마다 해당 종류의 수집 개수가 늘어난다. 첫 모자·모션·배경은 각각 왕관, 인사 모션, 별빛 배경을 사용할 수 있게 한다. 이후 보상은 같은 종류의 수집 개수로 표시한다. 쿠폰은 상점 연결 전까지 사용 기능이 없다.
- Lv.50/77/99 칭호는 문서의 이름을 사용하며, 가장 높은 칭호를 상태 패널에 표시한다.
- 옷장 선택은 기존 강아지 상태와 함께 기기에 저장한다. 기존 저장 데이터도 읽을 수 있다. 가족 간 꾸미기 동기화는 포함하지 않는다.
- 레벨업 시 돌봄 애니메이션을 마친 뒤 예고 말풍선, 반짝임과 성장 모습 전환, 해금 안내를 순서대로 표시한다. 재접속 시 이미 달성한 레벨의 연출은 반복하지 않는다.

Windows 한글 경로에서는 `Frontend/mira/run.ps1 -Mode verify`로 분석과 테스트를 실행한다.
